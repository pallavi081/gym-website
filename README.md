## ✨ About

**FitPhysique Pro** is a modern and responsive gym website focused on delivering a premium fitness experience with clean UI, smooth animations, and interactive components.

---

## 🚀 Features

- 💪 Modern Gym Landing Page
- 🔐 Login & Signup UI
- 📊 BMI Calculator
- 🌙 Dark Mode
- 📱 Fully Responsive
- ⚡ Smooth Animations

---

## 🛠️ Tech Stack

- React.js
- Next.js
- Tailwind CSS
- Firebase
- JavaScript

---

## 📂 Run Locally

```bash
git clone https://github.com/pallavi081/gym-website.git

cd gym-website

npm install

npm run dev
```
